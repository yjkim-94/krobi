# Krobi — stage1 prompts (paste into Nano Banana)

One code block = one complete prompt. Copy a whole block, paste it, generate that
animation's 8-frame strip.

## idle

```
HD-2D pixel art, "simple HD" JRPG overworld-sprite style (Octopath Traveler / HD-2D lineage).

[PROPORTIONS] Super-deformed mini-heroic build. For this non-bipedal blob creature,
a compact rounded mass with restraint; never realistic.
[FACE/EYES] Small simple eyes: 1-3 px dark almond/dot eyes with at most a single 1px
highlight; expressive via shape and brow, NOT via size. Minimal few-pixel mouth.
NO big glossy anime/chibi eyes, no large white sclera.
[OUTLINE] NO black keyline. Selective/colored outlining only: edge pixels are a darker
shade of the adjacent LOCAL color (dark-teal edge on a teal body). The silhouette reads
by value contrast against the background, not a black border.
[PALETTE] Muted, desaturated teal/mint palette, slightly grayed and harmonious
(~12-16 colors). NO neon, no pure-saturated primaries, no gradients/airbrush.
[SHADING] Soft banded cel shading: base tone + 1 shadow + occasional 1 highlight.
Consistent light from upper-left. Tiny specular dots only on the wet surface.
[PIXELS] Clean, deliberate pixel clusters; crisp edges; no dithering, no stray pixels.
Render LARGE but designed to read cleanly when downscaled to ~64 px.
[CANVAS] Solid flat magenta #ff00ff background only, creature centered, no baked ground
shadow. Leave clear padding around the whole strip; NO frame touches any canvas edge.

Creature: Krobi, a stage-1 youngling slime — a small, compact round blob slime. Glossy
wet body in muted desaturated teal with a soft mint-green top highlight and a couple of
tiny water-droplet specular dots; selective dark-teal colored edge (no black outline).
Small simple dark dot eyes (no white sclera) and a tiny mouth; expression via brow/shape.

[FRAME STRIP] 8 frames in one horizontal row, evenly spaced, same baseline, even margin
at both ends — no frame touches an edge.
[INVARIANTS — identical in all 8] same creature, colors, edges, overall size, ground
position, camera. Only the body silhouette changes per MOTION.
[MOTION — gentle breathing, one smooth loop] F1: neutral resting. F2: exhale, slightly
squashed (shorter/wider). F3: deeper squash. F4: deepest squash (lowest, widest). F5:
rising back toward neutral. F6: inhale, slightly stretched (taller/narrower). F7: more
stretch. F8: peak stretch (tallest, narrowest). Loops back to F1 seamlessly.

Do NOT: text, UI, multiple creatures per frame, black keyline outline, big anime/chibi
eyes, gradient/airbrush shading, realistic/3D shading, neon colors, baked ground shadow.
```
